# A/B Testing Tool Prototype

Статический кликабельный прототип по спецификации `specification.md`.

## Запуск

Из этой директории:

```bash
python3 -m http.server 4173
```

Затем откройте в браузере:

```text
http://localhost:4173
```

Также можно открыть `index.html` напрямую, но локальный сервер ближе к обычному веб-запуску.

## Что реализовано

- Главная страница с активными и завершёнными тестами.
- Создание теста с динамической подсказкой для целевого процента.
- Моковый подбор тестовой и контрольной групп с ручным кликабельным выбором магазинов.
- Блокировка магазинов, уже участвующих в активном тесте.
- Tooltip занятого магазина со ссылкой на соответствующий тест.
- Назначение планограммы только тестовой группе.
- Пересчет статусов активных тестов при открытии главной страницы.
- Явное завершение теста и финальный отчет.
